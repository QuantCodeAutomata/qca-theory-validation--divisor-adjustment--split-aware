# data/

This directory stores synthetic price-path data generated by the experiment
scripts in `exp/`.

## Contents

Files are written by experiment scripts and follow this naming convention:

| Pattern | Source experiment | Description |
|---------|-------------------|-------------|
| `two_asset_*.parquet` | `exp1_divisor_adjustment.py` | Two-asset paths with a single scheduled split used to validate the divisor update rule. |
| `self_financing_*.parquet` | `exp2_self_financing.py` | Two-asset paths together with portfolio holdings and defect series for the self-financing validation. |
| `split_reset_*.parquet` | `exp3_split_reset.py` | Multi-period split-reset paths illustrating Example 3.5 dynamics. |
| `multi_asset_*.parquet` | `exp4_diversity_portfolio.py` | Five-asset paths with heterogeneous splits used for diversity-portfolio comparisons. |

## Format

Each `.parquet` file contains a `pandas` DataFrame whose columns depend on the
number of assets `d`:

* `t` — integer time index starting at 0.
* `P_{i}` — raw (unadjusted) price of asset *i* at time *t*.
* `N_{i}` — number of shares outstanding for asset *i* at time *t*.
* `S_{i}` — market capitalisation of asset *i* (`P_i * N_i`) at time *t*.
* `m_{i}` — split multiplier for asset *i* at time *t* (1.0 on non-split days).

Parquet files are excluded from version control (see `.gitignore`).  To
reproduce all data files, run the experiment scripts in order:

```bash
python exp/exp1_divisor_adjustment.py
python exp/exp2_self_financing.py
python exp/exp3_split_reset.py
python exp/exp4_diversity_portfolio.py
```
